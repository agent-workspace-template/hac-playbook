# Playbook に聞く（playbook-qa）

AI に任せていて出た疑問に、2段で答える。1段目は Playbook の本文だけを根拠にし、型番号（例：B-1）を添える。2段目は Playbook に無い質問に、「Playbook 外」と明記した上で一般の知識で答える。どちらを根拠にしたかを、答えの中で必ず区別する。Playbook とこの Skill は同じ配布 repo に入っていて、`~/.agents/skills/playbook-qa` はその clone 内の `playbook-qa/` へのリンク。clone の場所は問わない。書き換えない。

## 0. 更新の確認（毎回、答える前に）

```bash
bash ~/.agents/skills/playbook-qa/check-update.sh
```

- 出力の1行目と「版:」の行を、答えの冒頭にそのまま添える。`PLAYBOOK:` の行が本文の場所で、以降の `$P` はこれを使う。取り込みがあった場合は、この SKILL.md も更新されているので読み直す。
- `NG:` で止まったら、その出力を伝えて終了する（clone が無い・手元の変更がある・取り込めない）。
- `WARN:` は続行する。手元の版で答えたことを明記する。

## 1. 読むもの（全文は読まない。索引 → 該当項目の順）

Playbook は 900 行あるので、`section.sh` で必要な節だけ取り出す。他のファイルは読まない。`$P` は 0 の `PLAYBOOK:` 行のパス。

1. 型の番号が分からない質問は、まず「場面索引」だけを読む（約 40 行）。

```bash
bash ~/.agents/skills/playbook-qa/section.sh "$P" index
```

2. 索引で当たりを付けた型（例：B-5）の項目だけを読む（約 20 行）。複数なら繰り返す。

```bash
bash ~/.agents/skills/playbook-qa/section.sh "$P" B-5
```

- 「土台」「はじめに」など考え方そのものの質問だけ、その節を取り出す：`section.sh "$P" 土台`
- 索引に当たりが無ければ `section.sh "$P" list` で見出し一覧を見て探す。それでも無ければ 2 の「2段目」へ進む。

## 2. 手順

1. 0 の確認結果を控える。
2. **1段目（Playbook にある）**：1 で取り出した節だけを根拠に答える。根拠にした型番号か節名を添える。本文に無いことを足して補わない。
3. **2段目（Playbook に無い）**：まず「Playbook には書かれていません」と1行で明記する。その上で、一般の知識で答える。次を守る。
   - 道具の操作（設定・コマンド・画面）を答えるときは、確かめ方（実行するコマンド、見る画面）を添える。版や環境で変わることは「変わりうる」と書く。
   - 「もっと良いやり方」を聞かれたら、Playbook に近い型があれば先にそれを挙げ、その先の提案は「Playbook 外」として分ける。
   - 断定できないことは断定しない。推測は推測と書く。
   - 質問に含まれる仕事の事情は、答えの中で繰り返さない（G-1）。
4. 答えの型：
   - 1行目：更新の確認結果（0 の出力）
   - 結論
   - 根拠のラベルを1行：`根拠：Playbook A-1` または `根拠：Playbook 外（一般の知識）`。両方使ったら両方書く
   - 要点を 2〜3 行。Playbook の項目は全文を転記しない（本人が本文を読む前提）
   - 2段目で答えた質問は、最後に「この質問は Playbook に無いので、場面を添えて配布担当者に送ると次の版の材料になる」と1行添える

## 3. 書き込み先と書式

- 何も書き換えない（clone の fast-forward 取り込みだけは 0 のスクリプトが行う）。
- 外部送信（メール・投稿）はしない。

## 4. 完了時に伝えること

確認した版、根拠のラベル（Playbook の型番号／Playbook 外）、Playbook に無かった質問の有無。
